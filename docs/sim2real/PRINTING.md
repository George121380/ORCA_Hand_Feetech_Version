# ORCA printables-v4 / A1 mini / 0.4 mm / PLA

首选候选笔：总长210mm，Ø16×146mm圆杆，两头各10mm肩部与24×24×22mm方头。方块55mm。210mm经过尺寸/干涉/理想可见性筛查，尚不是实物或训练验证的最优尺寸。

## 打印笔：同一工程打两次

打开 **pen-split-a1mini-pla.3mf**。一盘是一片210×24×12mm同形半壳，加3根定位销，沿床面对角线45°已摆好。接缝平面朝下、圆弧朝上，保持100%，不要自动重排。

完整打印两盘：得到2片半壳、3根使用销和3根备用销。单片平面包络165.46×165.46mm；计入3mm brim和0.1mm间隙，离180mm床边最小约4.17mm。无外部支撑，盲孔顶部需约4.3mm小桥接。

PLA工艺：层高0.2mm，4层壁，20% gyroid，顶底各5层，brim3mm、象脚补偿0.15mm，外墙40、内墙60mm/s，加速度1000mm/s²。均写入原生3MF。

Bambu Studio 2.5切片：单盘60层/12mm、估计用料21.18g、模型1h18m、总计约1h26m。两盘约2h52m，用料含brim和备用销，不是成品质量。尚未实际打印。

pen-split-a1mini.3mf是已摆好的标准毫米网格，需自行选A1 mini与工艺。pen-half.stl需2片、绕床面转45°，pen-alignment-pin.stl总共需3根。pen.stl、pen.scad、pen-assembly-reference.3mf是完整装配外形参考，不能当无支撑一体件直接打印。PETG工程只在换材料时使用，当前确认材料为PLA。

## 装配

两片同形，沿Z=0面对合。销Ø4×6mm，孔Ø4.3、深3.15mm，位于轴向Y=-94/0/+94mm。先去毛边、试装，不强压。接缝薄涂适用于PLA的胶、夹紧至固化；不要让胶或接缝台阶进入外部圆杆和标签面。定位销只负责对齐，胶接强度与公差尚未经实打。

## 方块

打开cube-a1mini-pla.3mf，55×55×55mm平面朝下。0.2mm层高，3层壁，20% gyroid，顶底各5层，8mm brim。同几何/工艺已有本机切片：275层，估计60.13g（含brim），总计4h06m；未实打。

## 纸质标签与相机标定

print-kit-a4.pdf共6页：方块标签、笔两端标签、固定参考码、20mm棋盘格、尺寸/装配、ID/朝向与验收记录。

第1-3页A4竖向，第4页A4横向，第5-6页为说明。全部用“实际大小/100%”，关闭“适应/缩小页面”。量100mm尺与黑框边长，保留白边，裁掉说明字和箭头。哑光不透底白纸或贴纸，不覆反光透明胶。第4页9×6内角点，标定用 --cols 9 --rows 6 --square-m 0.02。

- 方块ID0..5：黑框32mm、白纸40mm，面中央，四边各余7.5mm。侧面码顶边朝+Z，顶/底面码顶边朝+Y。
- 笔侧面黑框16mm、白纸20mm；负端ID10/12/14/16，正端11/13/15/17，对应+X/+Z/-X/-Z。顶边都朝+Y。
- 侧码中心Y=±94mm，基线188mm。24×22mm面中央贴纸，宽向各余2mm、轴向各余1mm。
- 外端面ID18在Y=-105mm、ID19在+105mm，码顶边都朝+Z；圆杆不贴码。
- 参考码ID40：黑框50mm、纸66mm，贴在平整刚性板上固定在手旁。不要贴在活动手指上。

图案及纸尺寸与v3相同，已打印贴纸可复用；**物体几何、标签位置JSON、策略必须同为v4**，不能沿用170mm版坐标。

## 实物验收

测量总长、杆径、方头、翘曲和接缝台阶；称量去brim、粘好、贴码的成品，用 --mass-kg 输入训练配置。55g方块和40.2g笔只是名义初值。20%填充不等于密度20%；外壁、接缝、孔壁、胶和纸都会加料。默认惯量为均匀实体近似，还需辨识或随机化。不要自行加未建模配重。

先静态检码和坐标方向，再dry-run。当前没有实打、胶接强度、训练收敛或真机成功率。
